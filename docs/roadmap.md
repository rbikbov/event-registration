# Дорожная карта

Фазы работы до сдачи (2026-11-05). Статус фазы — в заголовке: `не начата`, `в работе`,
`готова`. Фаза готова, когда выполнены критерии, `make check` проходит, а строки таблицы
«требование → тест» в README для её требований ссылаются на реальные тесты.

Задачи небольших фаз — списком прямо здесь. У крупных механизмов (фазы 1, 2, 4) — свои
`docs/features/<slug>/spec.md` и `tasks.md`, здесь только ссылка. Задача отмечается `[x]` в
том же коммите, который её выполняет (хэш в тот же коммит не вписать — он зависит от
содержимого); какой коммит что закрыл — `git log -- docs/roadmap.md`.

Как вести этот файл — skill `session-handoff` (`.claude/skills/session-handoff/`).

## Фаза 1. Регистрация, лист ожидания, отказ — не начата

Spec и задачи — `docs/features/registration/`. Критерии: повторная регистрация не создаёт
второго места; при нехватке мест — лист ожидания; отказ повышает первого из листа; тест
гонки за последнее место на Postgres.

Email участника нормализуется только по регистру: точки и `+tag` значимы, канонизации под
провайдеров (Gmail) нет — решение от 2026-10-28 22:38 в `docs/decisions.md`. Тест: адреса,
отличающиеся только регистром, — одна регистрация; с точкой — разные. В README — оговорка
«один email — одно место; разные адреса одного ящика (точки и `+tag` в Gmail) считаются
разными».

## Фаза 2. Outbox, воркер, письма — не начата
